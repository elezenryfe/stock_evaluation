Document Discovery
16
EDGAR Path: GET submissions JSON → scan filings (last 180 days) → find 8-K + 10-Q with EX-99 exhibits → download + strip HTML → quality check (≥200 words, ≥2 financial keywords, <15% non-ASCII) → SHA-256 deduplicate. Max 2 EDGAR docs.
17
News Path: Google News RSS search for "{company} earnings guidance EPS forecast" → scrape up to 5 articles (httpx for static, Playwright for JS-rendered) → same quality checks + dedup
18
Sort by priority: SEC_8K → SEC_10Q → SEC_10K → press_release → news_article

LLM Guidance Extraction
19
For each document: compute cache key (SHA-256(source_type + ":" + text)[:16]) → check .llm_cache/
20
CACHE MISS: run _smart_excerpt() → find "outlook/guidance" section → extract ~4000 chars → reduces tokens by 75–92%
21
Select prompt template by source type → call llm.extract_guidance() → DeepSeek returns JSON guidance items
22
HallucinationGuard.filter_valid_items() → validate EPS within 200% of TTM EPS, Revenue within 500% → remove invalid items
23

Single Document Call Flow

STEP 01
Prepare Prompt
Select template by source type:
earnings_call → EARNINGS_CALL_PROMPT
SEC_8K / SEC_10Q → SEC_8K_PROMPT
news_article → NEWS_ARTICLE_PROMPT
default → GENERAL_EXTRACTION_PROMPT

Inject document excerpt: {document_chunk}
STEP 02
Sanitize Text
• Smart quotes → straight quotes
• Em-dashes → --
• Non-breaking spaces → space
• Non-ASCII → '?'
• Collapse multiple spaces
• Collapse 3+ newlines to 2
STEP 03
Call LLM + Retry
client.chat.completions.create(...)
On RateLimitError (429): wait 2^attempt s, retry
On APIStatusError: wait + retry up to 5 attempts
On any Exception: wait 1s, retry
All fail → return {}
STEP 04
Parse Response
Strip ```json fences if present
json.loads(raw)
On JSONDecodeError → _repair_json():
• Remove trailing commas before ] or }
• Extract via regex \{[\s\S]*\}
• Retry parse → return ExtractionResult

The 4 Prompt Templates

General Extraction
GENERAL_EXTRACTION_PROMPT
Default fallback. Extracts all forward-looking management guidance — metric, numeric value/range, period, verbatim quote.
Trigger: any unrecognized source type
Earnings Call
EARNINGS_CALL_PROMPT
Handles speaker labels like [CEO], [CFO]. Extracts only management guidance, not analyst questions. Identifies raised/lowered/reiterated guidance.
Trigger: source_type = "earnings_call"
SEC 8-K / 10-Q
SEC_8K_PROMPT
Targets "Outlook" or "Guidance" sections. Explicitly excludes historical financial tables. Extracts only future projections from management.
Trigger: SEC_8K, SEC_10Q, SEC_10K
News Article
NEWS_ARTICLE_PROMPT
Distinguishes direct management quotes vs journalist summaries vs analyst opinions. Sets extraction_confidence = 0.5 for all news items.
Trigger: news_article, press_release

Hallucination Guard

EPS Validation (200% deviation max)
TTM EPS: $5.00 → Extracted: $0.89
deviation = |0.89–5.00|/5.00 = 82.2%✓ PASS
TTM EPS: $5.00 → Extracted: $50.00
deviation = |50–5|/5 = 900%✗ REJECT
Revenue Validation (500% deviation max)
TTM Revenue: $100B → Extracted: $43B
deviation = |43–100|/100 = 57%✓ PASS
Quote: "revenue was $10B" → Claimed: $180B
No number within 10% of $180B in quote✗ REJECT

Confidence Score: The Complete MathTwo-layer scoring: guidance quality → valuation reliability

Layer 1: Guidance Confidence

40%
Source QualityAvg weight of source types: SEC_8K=1.0, news=0.5, analyst=0.3
20%
Source Diversitymin(unique_sources / 3, 1.0) — rewards multiple independent sources
20%
Consensus Tightness1 – (std_dev / mean) × 5 — low spread = high score. +0.1 if only 1 EPS item
10%
RecencyLinear decay over 90 days: max(0, 1 – days/90)
×
Guidance Type Modifierinitial×1.0, reiterated×0.95, raised×0.9, lowered×0.85, analyst×0.6, ambiguous×0.4
–
Hallucination Penalty–0.1 per hallucination flag detected

Layer 2: Valuation Confidence

70%
From Guidance Confidenceguidance_conf × 0.7 (normal path)
30%
PE History Bonusmin(pe_observations / 20, 1.0) × 0.3 — more data = more confidence
×0.5
Negative EPS CapIf EPS negative → valuation_conf = guidance_conf × 0.5
×0.6
No Guidance PenaltyIf no extracted guidance → guidance_conf × 0.6 (analyst consensus only)

Decision Tree

// 3 valuation paths: if negative_eps and pe_result: → P/S Ratio Fallback ps = market_cap / revenue_ttm estimated = ps × 0.8 // 20% haircut method = "ps_ratio_fallback" low_confidence = True elif pe_result and guidance_eps > 0: → Historical PE (main path) estimated = guidance_eps × median_pe bull = guidance_eps × p75_pe bear = guidance_eps × p25_pe method = "guided_eps_x_median_pe" elif guidance_eps > 0 and pe_ttm > 0: → Current PE fallback estimated = guidance_eps × pe_ttm bull = estimated × 1.3 bear = estimated × 0.7 method = "forward_eps_x_current_pe" low_confidence = True

PEG Sanity Check

growth = (forward_eps - eps_ttm) / eps_ttm peg = pe_ttm / (growth × 100) peg < 1 → "potentially undervalued" peg < 2 → "fairly valued" peg < 3 → "somewhat overvalued" peg ≥ 3 → "potentially overvalued"

PE Calculator Algorithm

// calculate_historical_median_pe(ticker, client, years=5) 1. Get monthly price history for {years} years → prices["Close"].resample("ME").last() 2. Get quarterly EPS history (~20 quarters) → stock.quarterly_income_stmt → "Diluted EPS" 3. For each month-end price: a. Find 4 most recent quarterly EPS values (TTM window) b. Sum them → TTM EPS c. If TTM EPS > 0: PE = price / TTM_EPS d. Gap check: reject if gap > 150 days between quarters 4. Compute statistics on all valid PE observations: median_pe = np.median(pe_series) // used for base estimate p25_pe = np.percentile(pe_series, 25) // bear case p75_pe = np.percentile(pe_series, 75) // bull case 5. Return None if < 5 observations (insufficient data)

Weighted Median Result
$5.00 EPS
Why weighted median, not mean? Robust to outliers — if one source reports wildly different guidance (e.g., different fiscal year interpretation), it doesn't skew the result as a mean would.

Error Handling & Graceful DegradationEvery failure path and its impact on the final result
llm_extraction_succeeded
Positive flag — extraction worked
Full guidance available from documents. Highest confidence path.
yfinance_rate_limited_using_twelvedata
Primary data source throttled
No PE history available (Twelve Data lacks quarterly EPS). PE-based valuation disabled, falls back to P/S.
document_fetch_partial
Some documents couldn't be fetched
Fewer sources for LLM extraction. Lower source diversity score.
no_documents_found
Zero documents discovered
Falls back to analyst consensus. guidance_source = "analyst_consensus". Confidence penalized (×0.6).
llm_extraction_failed_using_fallback
LLM extraction failed
Uses forward_eps from yfinance instead. Lower confidence. Degraded = true.
valuation_failed
Could not compute valuation
Request fails with HTTP 502. No result returned.
no_extracted_guidance
No extracted guidance available
Falls back to analyst consensus from yfinance forward_eps.
Degradation detection: is_degraded = any("failed" in f or "no_" in f for f in flags) — A degraded analysis still returns results but with lower confidence scores and flags in the response.
